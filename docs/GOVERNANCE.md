# Security and Governance Framework

- Microsoft Entra ID for authentication
- Fabric workspace RBAC using least privilege
- Power BI RLS with user-to-patient authorization mapping
- OneLake security for governed access
- SourceReport carried into Gold for evidence traceability
- Microsoft Purview lineage and sensitivity labels
- Audit logging for access and processing
- Documented retention and deletion rules
- Synthetic data for the POC
- Formal legal review for India's Digital Personal Data Protection Act, 2023 before production
